# 用户 Skill 初始化说明

系统只区分内置 Skill 和用户 Skill。本文件是维护说明，不发送给 Agent。

安装包可附带初始用户 Skill。首次识别时将正文和资源复制到用户目录，默认关闭；之后与普通用户文件完全相同，可直接编辑、开关、排序、导出和删除。initializedUserSkills 记录已处理项，防止重启和升级覆盖修改或恢复删除。已有相同 ID、同名内容或旧版同名个人副本时保留，不再追加。旧 deletedSkillTemplates 只用于迁移时尊重用户已有删除选择。

初始资源目前保留在安装包 skill-templates 目录以兼容分发路径；该目录仅作首次复制来源，不再公开模板类型、模板目录接口或只读模板视图。任务组合只读取已启用的内置和用户文件。

附带漫画的规则、示例与内容指纹继续保全，初始化不重写正文。测试检查首次默认关闭、可直接编辑与启用、删除不恢复、既有副本不覆盖以及打包资源路径；真实用户数据不用于测试。详见 [验证说明](testing.md)。
