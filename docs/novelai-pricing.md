# NovelAI 费用预估

核对日期：2026-11-04。预估与授权共用 `src/shared/generation/pricing.ts`。

当前只覆盖本应用发送的 V4.5 Full、V5 Full 高质量及其重绘模型、图生图和 2× 放大。没有接入未经公开文档确认的报价端点。

依据为 [NovelAI 官方网页计算器](https://novelai.net/_next/static/chunks/274ff5q_u23hy.js) 的模块 643656，以及网页参数转换和免费条件模块 108295。网页更新后文件名可能变化，需从 [官方生图页](https://novelai.net/image) 重新定位。接口字段依据 [官方 Image API schema](https://image.novelai.net/docs/doc.json)。

- 普通生成基础价格：向上取整 `(2.951823174884865e-6 + 5.753298233447344e-7 × steps) × width × height`。
- V5 再乘 1.5，图生图和局部重绘再乘实际发送的强度，向上取整，最低 2 Anlas。当前请求关闭 SMEA；未支持的模型、无效参数和官方价格大于 140 的错误状态不推测价格。
- 有效 Opus、总像素不超过 1,048,576、步数不超过 28 时可免费；V5 还需要非负免费额度。本应用的 2% 保护阈值是授权保护条件，不是官方计价规则。
- 每次请求只生成一张。V4.5 免费条件满足时连续多张按 0 估算；V5 多张显示区间，因为后续图片的免费额度无法预知。每张提交前重新评估，可能扣费时仍单独授权。
- 放大按输入像素计算：不超过 1,048,576 / 1,747,627 / 2,446,678 / 3,145,728，分别为 1 / 2 / 3 / 4 Anlas。
- 账户信息缺失显示范围或未知，不冒充已确认免费。预估不是锁价，最终由服务端决定。

执行后对比两类 Anlas 余额，并显示剩余总额；V5 另显示免费额度变化的百分点。工作台将反馈保存到操作记录，任务进度及生图结果也显示观测值。查询失败显示未知；账户充值、额度恢复或其他客户端并发操作可能影响差值，因此文案使用“余额变化”，而非单次账单。

当前按 [本机开发验收](testing.md) 使用现有配置与数据验证预估、授权及执行后余额。`npm run check:full` 完成自动真实灰度部分，涉及 MCP、AI 或工作台行为时还须完成外部 Agent 的实际上下文读取、看图、方案采纳和执行；需要收费的分支须真实执行并保留操作、图片与额度证据。

历史 `node scripts/check.mjs pricing operations:policy` 曾使用固定官方样例和模拟接口。该入口现已明确拒绝执行，源码仅供追溯，不能作为当前验收依据。
