# 图标语义对照

图标定义在 `src/renderer/src/shared/ui/icons.ts`：24×24 画布、1.8 圆头描边、圆角转折，按 NovelAI 的线性语汇自绘。一个含义只对应一个图标；新增按钮先查本表，含义不符时新画一个，不拿外形相近的图标凑数。按钮、提示和状态里的图标一律用 `<Icon>`，不用 `×`、`✓`、`→`、`＋` 等文字符号或内联 SVG 代替；正文里的差异标记（`＋`/`−`）和快捷键说明不在此列。
