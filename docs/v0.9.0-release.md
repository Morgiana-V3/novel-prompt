# v0.9.0 发布记录

对比基线为已发布的 [v0.8.0](https://github.com/Morgiana-V3/novel-prompt/releases/tag/v0.8.0)（提交 `a88091a`）。本版包括基线之后的图片反推、图片收藏、任务提示与兼容修复；打包版本为 `0.9.0`。

## 用户可见增量

| 功能         | v0.8.0                           | v0.9.0                                                                               |
| ------------ | -------------------------------- | ------------------------------------------------------------------------------------ |
| 图片反推     | 没有本地识别入口                 | WD 内容识别、K2 / K3 画师推荐、可选 PixAI 角色识别；下载、校验、导入和删除模型       |
| 画师比较     | 使用普通生图自行调整             | 独立识别与试图两步流程，固定条件比较画师串，综合候选、权重、无画师对照与 K3 风格排序 |
| 收藏         | 以配置记录和缩略图为主           | 独立保存图片及生成记录，统一星标入口、同配置种子归组、普通图库、搜索、查阅与明确载入 |
| 图片生成记录 | 生成记录保存在图片旁的 JSON 中   | 新图内嵌完整记录，支持导入恢复；兼容旧 JSON，不重写历史原图                          |
| 异步任务     | 已有任务中心，部分提示仍留在页面 | 更多后台操作纳入任务中心；紧凑状态和加载动画，修正工作台资料计数                     |
| 编辑和账户   | 原有表单与账户入口               | 集中账户额度与连接状态、保存 Token、关闭拼写红线、恢复窗口位置与大小                 |

收藏总览采用普通网格，无分页和无限加载。浏览图片只替换收藏页的详情；点击「载入配置」才更新当前提示词与生成参数，保留种子选项与操作位于同一行。

## 本次发布整理

- 沿用原 README 的结构、标题、正文和截图，补充图片收藏、综合画师推荐、任务提示及旧记录兼容说明；同步相关使用指南、测试说明与更新记录。
- 删除 `tests/integration/mcp-smoke.mjs` 和 `tests/integration/mcp-read-smoke.mjs`：它们依赖真实开发目录或已有项目，其有效检查已有隔离宿主、连接、上下文、索引与性能测试覆盖。
- `npm run mcp:smoke` 改用隔离测试入口。保留图片保留、工作台清理、Skill 指纹、安装升级等有实际回归价值的测试。
- 完整检查加入收藏的开发模式启动和账户设置检查；修正旧按钮定位、缺失的模拟接口，以及仍假定新图具有旁置 JSON 的夹具。
- 补齐 v0.8 记录兼容：旧版原始请求优先于供应商展开后的提示词，新版内嵌记录优先于旁置文件；图库直接导出保持原文件校验值，收藏导出携带完整记录。
