# Skill 文档组织与加载

本文件是开发维护说明，不作为 Skill 正文发送给 Agent。规则是否生效由本轮启用配置、功能范围和目标模型决定，不由本文件列出的内容决定。

## 加载边界

| 层级 | 是否固定生效 | 职责与边界 |
| --- | --- | --- |
| `skills/core.md` 与当前程序协议 | 是 | 总则负责识别本轮启用规则、读取与优先级；程序协议约束接口和可执行能力。不得借此恢复已关闭 Skill 的内容 |
| 内置 Skill | 否，可分别关闭和排序 | 启用且适用时提供自身职责内的完整规则；单独启用也能工作，不依赖另一篇必然存在 |
| 用户 Skill | 否，按配置启用和排序 | 与其他启用篇目按同一优先级机制组合，不要求存在内置规则作为前置依赖 |


`composeSkills` 先按启用状态、功能范围和模型筛选。普通功能只组合其范围及 `scope=all`；工作台先保存已启用且适用模型的清单，再由本轮任务选择所需范围。没有相关篇目时使用用户要求、程序协议与通用知识，不自动重新启用规则。全部关闭、仅用户规则、内置规则的任意子集均是有效配置。

启用状态与顺序随用户配置变化；文档维护不重置这些设置。已提交讨论保留发送时的冻结规则，后续开关变化只影响新请求。用户文件不因软件附带初始资源更新而自动改写。软件附带的漫画直接初始化为默认关闭的用户 Skill；已有用户版本保留，删除后不再补回。

## 内容组织

| Skill | 入口保留 | 参考文件 |
| --- | --- | --- |
| 提示词编排 | 执行流程、任务边界、一致性、角色与文字、负面与模型、风格与统计、语法与输出复核 | 组合示例（1 份，不承载独有的必需规则） |
| 画面推测 | 全部常用规则，包括角色区域、负面误伤与证据边界 | 无需补读 |
| 局部重绘 | 执行流程、工作边界、遮罩与强度、字段归属、语法文字、最小修改、输出契约与四组示例 | 无需补读 |

目前三份内置规则各自使用 `skills/<名称>/SKILL.md`，稳定标识为 `builtin:prompt`、`builtin:preview`、`builtin:inpaint`。上表说明各篇自身的组织，不代表三篇始终一起加载。只有启用且适用于本轮时，才要求取得该篇完整入口。每套都有编号执行流程；编排另保留提示词排列顺序。并列主题与规则使用无序列表，引用使用主题名及可验证链接。型号、权重、坐标、优先级和画格位置等有实际含义的数字保留。

完整规则加载不等于扩大任务范围：创建、整体优化、最小修改和仅评估分别应用对应条件，不自动启动全套查词和重编排。完整方案不等于必须加载完整范例；仅在索要范例或结构仍有歧义时补读组合示例。预览与重绘各自包含所需的字段和解析约束，不隐式依赖未启用的编排 Skill。

准确性优先于上下文体积。对本轮已启用规则，适用范围同时检查输入与本次将交付的字段，空白输入不使相关输出约束失效。每篇所需参考资料按自身入口的条件补读；读取其中一篇不能替代另一篇已启用且相关的规则。不得以“完整加载”为由跨过用户开关。

合并必须同时迁移链接、调用方与验收。已合入正文的旧资源不再列入当前目录，主题采用页内锚点；旧冻结快照仍使用其保存的正文与索引，不替换成当前文件。无序规则并不表示可选，有序流程也不允许跳过保真与最终核对。

具体创作策略由启用的 Skill 与用户要求决定；本维护说明不追加漫画、人物编排或其他创作规则。内置规则中的漫画分格、文字等通用场景能力属于该篇自身内容，不依赖某份漫画用户 Skill 存在。

## 读取接口与快照

内置 AI 随组合消息取得已启用入口，用 `read_skill_reference(id)` 补读本轮冻结参考资料，也支持 `ids` 数组批量读取；工作台外部 Agent 使用 `get_workspace_context(skills_task, skills_ids)` 读取本轮冻结目录中的正文。非工作台场景使用 `get_skill(id, resource)`。`skills_task:all` 返回本轮冻结清单中的全部正文，不会启用清单外的篇目；普通任务不应默认使用它。

`get_skill` 输出契约同时接受入口 `{id,name,content}` 与资源 `{id,path,content}`。同一消息链共享已读取状态，正文不重复注入；读取受整体预算约束，不能在业务循环中重新计算一套预算。

`missingRequiredIds` 只检查本轮冻结清单内选中的入口与显式请求的资料，不能证明模型已遵循规则。外部 Agent 选择 prompt / preview / inpaint 后取得清单内对应范围的完整入口；该范围没有已启用篇目不算漏读。正文已离开当前上下文时需重读，不能把目录当成正文。查询预算结束后应根据现有证据作答，说明未核实内容，不自动生图。

附带用户 Skill 的一次性初始化与迁移见 [用户 Skill 初始化说明](skill-templates.md)，不增加第三种 Skill 类型。

## 维护边界

完整提供已启用入口用于消除该篇必要资料漏读这一环节，不保证模型逐条遵循或成图达标。没有行为验证前，不因入口变长而重新拆分必要规则。上下文字符数、token、费用和耗时只作诊断，不能替代字段保真与实际任务结果。

内容保全、包内链接、稳定标识、复制导出、冻结读取与 MCP 输出契约由现有测试覆盖，入口见 [验证说明](testing.md)。真实模型的场景选择、最终字段保真和画面质量需要另外验收，不能用可解析响应或离线字符数替代。

回归不设置入口必须缩短到旧版某一百分比的门槛；体积只记为诊断数据。内容修订保留历史指纹，并单列修订原因及替代段落指纹，不通过整体刷新基线掩盖规则删除。真实对照应固定模型、思考设置、输入、工具和规则正文，分别改变按需/全文加载与编号/无编号；历史不同轮次或不同模型配置不能直接合并成成功率。

测试报告、截图、原始响应、规则对照快照与运行日志统一保存在项目外；本文件只维护当前设计，不累积历次执行结果。
